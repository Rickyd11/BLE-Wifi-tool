# BLE-Wifi-tool

An Cheap Yellow Display (CYD) ESP-32 based wireless monitoring system with a combine Bluetooth Low Energy (BLE) discovery, Wifi access point scanning, and a dashboard to display the information locally. 

This is a standalone wireless monitoring project built around the CYD. The project combines BLE device discovery and nearby Wifi access point scanning with a touchscreen interface and locally hosted dashboard.

The goal is to create a compact wireless monitoring station that provides visibility into nearby wireless activity without requiring a computer to operate it. 

# Features

Bluetooth Low Energy
- Passive BLE scanning
- Discovery of nearby BLE advertisements
- Collection and tracking BLE Observation

Wifi Access Point Monitoring
- Scan for nearby Wifi access points
- Collects available access-point information
- Tracks discovered wireless networks

Dashboard
- Home (Displaying the compiled information here)
- Wifi Monitoring Section
- BLE Monitoring Section
- Periodic Updates
